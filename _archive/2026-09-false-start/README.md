# Parked: September 2026 false start

Everything in this folder comes from the first attempt at the homepage
(uploaded 14 September 2026). It is kept for reference only.

**Nothing here is a source for the build.** The build works only from the
approved prototypes and documents in the `export` folder, and the only design
source is `DESIGN.md` v2.0 (Terracotta).

| Folder / file | What it is |
|---|---|
| `homepage-attempts/` | Three early homepage drafts (`.dc.html`) and the design-tool scripts they need to open |
| `images/` | Placeholder images those drafts used |
| `reference/` | A screenshot and two images from the live site (duplicates of `images/nolan-logo.webp` and `images/team-hero.jpg`) |
| `superseded-design-spec.md` | The old navy and sage design spec (was `design_1.md`). Superseded by `DESIGN.md` v2.0 |

If an image here turns out to be needed, it will be copied into the build's
image folder at that point, so the build never reads from this archive.

There is also an older branch, `claude/adoring-darwin-3iv1ig`, holding an
earlier tidy-up of the same files. It is superseded too.
